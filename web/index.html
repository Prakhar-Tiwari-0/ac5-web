Keyboard and mouse mappings

Focus the canvas to send input. Arrow keys: D-pad. Enter: Start. Right Shift: Select. X/S/Z/A: Cross/Circle/Square/Triangle. Q/E: L1/R1. 1/3: L2/R2. Numpad 4/6/8/2: left stick. Mouse drag: right stick. Standard-mapping controllers use browser Gamepad API positions. Aircraft actions depend on the original game’s settings.

Local retail build command

The developer compiler runs in the local terminal. After a valid executable is available, run from the repository root:

python3 scripts/prepare_upstream.py
python3 scripts/build.py --upstream .cache/upstream --emcc "$EMSDK/upstream/emscripten/emcc" --out build/retail --elf game/SLUS_208.51

Serve the output directory with python3 scripts/serve.py --build-dir build/retail. Browser file selection grants local read access; it cannot give the Python process a filesystem path.
